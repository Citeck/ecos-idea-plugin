Reports attributes of Citeck data types and aspects whose database column name is longer than 63 bytes.

The ECOS storage layer uses the attribute id as the database column name. For an aspect the column name is <prefix>:<attribute id>, where the prefix is the aspect prefix or, when it is blank, the aspect id.

PostgreSQL silently truncates identifiers longer than 63 bytes (NAMEDATALEN - 1; quoting does not help). The storage layer then cannot find the column by its full name, tries to add it again on every write and fails with column "..." already exists, so no record of the type can be saved.

Attributes that never become database columns are not checked: ids that cannot be a column name, ids starting with _ and computed attributes without a storing type (computed.storingType: NONE), whose value is recalculated on each read.

Shorten the attribute id. For an aspect attribute a short aspect prefix also helps, but note that the prefix is part of every column name of the aspect, so changing it on a deployed system renames all of them.
